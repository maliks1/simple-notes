**Simple Notes** adalah aplikasi catatan minimalis yang memungkinkan pengguna menulis, menyimpan, dan berbagi catatan secara instan tanpa memerlukan login. Setiap catatan disimpan secara otomatis dan dapat dibagikan melalui URL unik.

<!-- ![Simple Notes Preview](https://via.placeholder.com/800x500?text=Simple+Notes+Preview) *(Ganti dengan screenshot aplikasi)* -->

## Fitur

- **Tanpa Login** – Mulai menulis langsung tanpa perlu mendaftar atau login.
- **Simpan Otomatis** – Setiap perubahan disimpan secara real-time tanpa tombol *save*.
- **Bagikan dengan Mudah** – Salin URL unik untuk berbagi catatan dengan siapa saja.
- **Minimalis & Cepat** – Antarmuka bersih dan ringan untuk fokus pada tulisan.
- **Gratis & Source-Available** – Bebas digunakan dan dimodifikasi untuk keperluan non-komersial dengan atribusi.

## Teknologi yang Digunakan

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
- **Database:** [Supabase](https://supabase.com/) (PostgreSQL)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **ID Generator:** [NanoID](https://github.com/ai/nanoid)
- **Rate Limiting:** [Upstash Ratelimit](https://github.com/upstash/ratelimit)
- **Deployment:** [Vercel](https://vercel.com/) (rekomendasi)

## Instalasi & Penggunaan

### Prasyarat
- Node.js v20 atau lebih baru
- Akun [Supabase](https://supabase.com/) (gratis)
- Git (opsional)

### Langkah-langkah

1. **Clone Repository**
   ```bash
   git clone https://github.com/maliks1/simple-notes.git
   cd simple-notes
   ```

2. **Instal Dependensi**
   ```bash
   npm install
   ```

3. **Konfigurasi Supabase**
   - Buat project baru di [Supabase Dashboard](https://app.supabase.com/).
   - Buat tabel `notes` dengan struktur berikut:
     ```sql
     create table notes (
       id bigint generated by default as identity primary key,
       token text unique not null,
       content text,
       created_at timestamp with time zone default now()
     );
     ```
   - Salin `URL` dan `anon key` dari **Project Settings > API** di Supabase.

4. **Konfigurasi Environment**
   Buat file `.env.local` di root project dan tambahkan:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=URL_ANDA_DARI_SUPABASE
   NEXT_PUBLIC_SUPABASE_ANON_KEY=ANON_KEY_ANDA_DARI_SUPABASE
   ```

5. **Jalankan Aplikasi**
   ```bash
   npm run dev
   ```
   Buka [http://localhost:3000](http://localhost:3000) di browser.

## Cara Kerja

1. **Pembuatan Catatan Baru**
   - Pengguna mengakses `/notes` untuk membuat catatan baru.
   - Aplikasi menghasilkan token unik menggunakan `nanoid`.
   - Token digunakan untuk membuat URL unik (misal: `/notes/abc123`).
   - Catatan kosong disimpan di Supabase dengan token sebagai kunci.

2. **Penyimpanan Otomatis**
   - Setiap perubahan pada textarea dipantau menggunakan `useEffect`.
   - Perubahan disimpan ke Supabase setiap 1 detik jika tidak ada aktivitas mengetik.
   - Status penyimpanan ditampilkan di pojok kanan bawah.

3. **Berbagi Catatan**
   - Pengguna dapat menyalin URL halaman catatan (misal: `https://simple-notes.vercel.app/notes/abc123`).
   - Siapa pun yang mengakses URL tersebut dapat melihat dan mengedit catatan.

## 🔒 Keamanan

Meskipun aplikasi ini dirancang sederhana tanpa login, beberapa langkah
keamanan dasar tetap diterapkan untuk mencegah penyalahgunaan:

### 1. Rate Limiting
Pembuatan catatan baru dibatasi menggunakan
[Upstash Redis](https://upstash.com/) dengan algoritma **sliding window**
dua lapis:

- **Per visitor:** 3 catatan per 10 menit (berdasarkan cookie anonim)
- **Per IP:** 30 catatan per 10 menit (sebagai backstop anti-spam)
- **Tujuan:** Mencegah spam pembuatan token yang dapat memenuhi database
- **Implementasi:** Melalui `middleware.ts` di level edge Next.js

Pendekatan ini memastikan pengguna di jaringan yang sama (kantor, sekolah,
NAT) tidak saling memengaruhi kuota, sekaligus tetap membatasi upaya
spam dari satu alamat IP.

### 2. Row Level Security (RLS) Supabase
Tabel `notes` dilindungi dengan kebijakan RLS yang memungkinkan operasi
`insert`, `select`, dan `update` untuk role `anon`. Karena aplikasi ini
tidak menggunakan sistem login, kebijakan ini diperlukan agar fitur tetap
berfungsi, dengan rate limiting sebagai lapisan perlindungan utama.

### 3. Rendering Dinamis
Halaman `/n` menggunakan `export const dynamic = "force-dynamic"` untuk
memastikan setiap permintaan menghasilkan token baru dan mencegah caching
yang tidak diinginkan di lingkungan serverless seperti Vercel.

### Catatan Keamanan
Karena sifatnya yang tanpa login, siapa pun yang memiliki URL catatan
dapat melihat dan mengedit isinya. Jangan gunakan aplikasi ini untuk
menyimpan informasi sensitif atau rahasia.

## Deployment

### Vercel (Rekomendasi)
1. Hubungkan repository GitHub ke [Vercel](https://vercel.com/).
2. Tambahkan variabel environment dari `.env.local` di **Settings > Environment Variables**.
3. Deploy!

### Alternatif
- **Netlify**: Gunakan *Next.js Runtime* dan tambahkan variabel environment.
- **Railway**: Hubungkan repository dan tambahkan variabel environment.
